# Friends Auction

Telegram Mini App для небольшого аукциона личных вещей среди знакомых. Организатор публикует лоты, вручную допускает участников к ставкам и договаривается с победителями о самовывозе и оплате вне приложения.

Проект находится в разработке. Доступны локальная демонстрация и временный тест через Telegram. **Текущий тестовый режим предназначен для проверки: ставки в нём не являются настоящими.** Постоянное размещение для реальных торгов пока не настроено.

## Возможности

- Публичный каталог и карточки лотов; для ставок нужен вход через Telegram и одобрение организатора.
- Заявка с именем и фамилией, ручной допуск ко всем лотам и возможность отозвать его.
- Начальная цена от 0 ₽ и индивидуальный шаг; ставку можно повысить сразу на несколько шагов. При одновременных ставках сервер проверяет актуальную цену в транзакции.
- До шести фотографий на лот: JPEG, PNG, WebP или HEIC/HEIF, до 36 МБ на запрос. При загрузке изображения перекодируются в JPEG без исходных метаданных.
- История собственных ставок для участника; заявки и история всех ставок доступны организатору. Состояние открытого приложения периодически обновляется.
- Подписка на изменения по лоту, ежедневная сводка и уведомления в последний час торгов.
- Управление лотами и отметками о передаче. Если победитель отказался, организатор может выбрать следующего участника и отправить ему уведомление.

Оплата, адрес и передача вещи обсуждаются лично. Приложение не принимает платежи и не организует доставку.

## Стек и требования

- Python 3.11 или новее, Flask и Gunicorn; зависимости закреплены в [`requirements.txt`](requirements.txt).
- SQLite и локальное хранилище фотографий; интерфейс написан на HTML, CSS и JavaScript.
- macOS или Linux. Готовые файлы `.command` предназначены для macOS; на других системах используйте команды ниже. Gunicorn и процесс уведомлений рассчитаны на Unix-подобную среду.
- Для теста в Telegram дополнительно нужны отдельный бот, созданный через [@BotFather](https://t.me/BotFather), и `cloudflared`.

## Быстрый запуск демо

Демо работает только на этом компьютере, использует вымышленные данные и не требует бота.

```sh
git clone https://github.com/PaVeLlLlLX/friends-auction.git
cd friends-auction
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python demo.py
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080). В верхней части страницы можно переключаться между гостем, участниками и организатором, чтобы проверить заявку и ставку. Для остановки нажмите `Ctrl+C` в терминале.

На macOS вместо команд установки и запуска можно открыть **«Запустить демо.command»**. Демо хранит свою базу и фотографии в `data/demo.sqlite3` и `data/demo-photos/`.

> **Не размещайте демо в интернете.** В нём намеренно доступно переключение ролей без настоящей авторизации Telegram.

## Тест с другом в Telegram

Это отдельный от демо режим с настоящей проверкой Telegram-аккаунтов и учебными ставками. Доступ к каталогу получает любой, у кого есть адрес приложения; допуск к ставкам подтверждает организатор.

1. Создайте отдельного бота через [@BotFather](https://t.me/BotFather). Не отправляйте токен в чат и не добавляйте его в Git.
2. Установите зависимости из раздела выше. Установите [`cloudflared`](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/) и разместите исполняемый файл по пути `.tools/cloudflared`. Например, на macOS с Homebrew:

   ```sh
   brew install cloudflared
   mkdir -p .tools
   ln -s "$(command -v cloudflared)" .tools/cloudflared
   ```

   Если `.tools/cloudflared` уже существует, повторно создавать ссылку не нужно.
3. Запустите **«Подключить Telegram.command»** на macOS или выполните `.venv/bin/python scripts/setup_testing.py`. Введите токен в терминале, откройте бота, отправьте `/start` и подтвердите свой Telegram-аккаунт как аккаунт организатора. Настройки сохраняются в `data/testing-config.json` с ограниченными правами доступа.
4. Запустите **«Запустить тест для друга.command»** или выполните `.venv/bin/python scripts/start_testing.py`. Скрипт запустит приложение и процесс уведомлений, создаст временный HTTPS-адрес и обновит кнопку меню бота.
5. Откройте приложение через бота и поделитесь ссылкой на бота с другом. Оставьте Mac включённым и подключённым к интернету, а окно запуска — открытым. Для остановки нажмите `Ctrl+C`.

При каждом запуске Cloudflare Quick Tunnel выдаёт новый адрес. Если кнопка в старом сообщении больше не работает, используйте кнопку меню бота или отправьте ему `/start` заново. Тестовые данные находятся в `data/testing.sqlite3` и `data/testing-photos/` и не переносятся в реальный аукцион автоматически.

## Настройка приложения

Для постоянного размещения переменные окружения задаются **отдельно для веб-приложения и процесса уведомлений**. В скриптах временного теста они настраиваются автоматически.

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота; обязателен вне демо. | Нет |
| `TELEGRAM_ADMIN_ID` | Числовой Telegram ID организатора; обязателен вне демо. | Нет |
| `AUCTION_DB` | Путь к базе SQLite. | `data/auction.sqlite3` |
| `AUCTION_UPLOADS` | Папка загруженных фотографий. | `data/photos/` |
| `AUCTION_DEMO` | `1` включает локальное демо с переключением ролей. | Выключено |
| `AUCTION_TRIAL` | `1` включает маркировку теста и обработку адреса клиента для тестового Cloudflare Tunnel. Не включайте при доступе к серверу в обход доверенного туннеля. | Выключено |
| `AUCTION_BOT_POLL` | `1` разрешает процессу уведомлений отвечать на личные команды `/start` через `getUpdates`. | Выключено |
| `AUCTION_APP_URL` | HTTPS-адрес Mini App для кнопки в ответе на `/start`; нужен при использовании `AUCTION_BOT_POLL=1`. | Нет |
| `PORT` | Порт при запуске `python run.py`; к Gunicorn не относится. | `8080` |

### Даты и уведомления

Текущие даты заданы в коде и не управляются переменными окружения:

- Завершение торгов — **12 декабря 2026 года в 23:59:00 по Новосибирску**; продления нет. Ставки принимаются строго до этого момента.
- Окончание срока хранения — **1 февраля 2027 года в 00:00 по Новосибирску**, после чего API и фотографии становятся недоступны. Работающий процесс уведомлений удаляет данные из настроенной базы и загруженные JPEG-файлы; если он остановлен, очистка произойдёт после следующего запуска.

Для другого аукциона измените `END` и `DELETE_AFTER` в [`auction/app.py`](auction/app.py), а также даты, отображаемые в [`static/ru.json`](static/ru.json), и проверьте тесты. Автоматическая очистка **не удаляет** исходники и копии в `data/examples/`, другие базы, резервные копии, кэш Telegram и файлы на чужих устройствах.

После ставки участник подписывается на уведомления об участии; за лотом можно следить и отдельно. При наличии изменений сводка отправляется не чаще одного раза в день, начиная с 18:00 по Новосибирску. В последний час предусмотрены напоминание и сообщения о перебитых ставках. Для получения уведомлений пользователь должен начать диалог с ботом и не блокировать его.

## Постоянное размещение

Тестовый Quick Tunnel не рассчитан на постоянную работу. Для реальных торгов необходимы постоянный HTTPS-адрес, защищённое хранение и отдельная проверка развёртывания.

1. Установите зависимости и задайте обязательные переменные окружения без сохранения токена в репозитории.
2. Разместите SQLite и фотографии на постоянном локальном диске одного сервера. Настройте резервное копирование, права доступа, синхронизацию часов и последующее удаление всех копий данных.
3. Запустите веб-приложение за HTTPS reverse proxy. Например:

   ```sh
   .venv/bin/gunicorn --bind 127.0.0.1:8080 --workers 1 --threads 4 run:app
   ```

4. Отдельно запустите `.venv/bin/python -m auction.worker` с теми же настройками. Он отвечает за уведомления и очистку; на одном узле должен работать только один экземпляр. Для ответов бота на `/start` дополнительно задайте `AUCTION_BOT_POLL=1` и `AUCTION_APP_URL`. Не запускайте параллельно другой процесс, получающий обновления того же бота.
5. Настройте кнопку Mini App у бота и проверьте приложение в Telegram как минимум с двумя аккаунтами: допуск, ставки, фотографии, уведомления и ограничения доступа. Убедитесь, что тестовые ставки и заявки не перенесены в реальные торги.

Дополнительные сведения: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [развёртывание Flask с Gunicorn](https://flask.palletsprojects.com/en/stable/deploying/gunicorn/).

## Безопасность и данные

- Сервер проверяет подпись и срок действия Telegram `initData`; организатор определяется по Telegram ID, а не по изменяемому username.
- Имена из заявок и данные участников доступны организатору. Посетители видят публичные описания, фотографии, текущие цены и количество ставок.
- Токены, базы и фотографии по умолчанию находятся в игнорируемой Git папке `data/`. Перед публикацией изменений проверяйте файлы и историю коммитов на секреты.
- Встроенные ограничения запросов действуют в одном процессе и дополняют, но не заменяют защиту и мониторинг на reverse proxy. Приложение не проходило независимый аудит безопасности.
- При отзыве допуска новые ставки участника блокируются, но его прежние ставки автоматически не удаляются. Распределённый спам и компрометация Telegram-аккаунта или токена остаются возможными.

Об уязвимостях сообщайте владельцу лично, не публикуя секреты и персональные данные в открытых issue.

## Разработка и тесты

```sh
.venv/bin/python -m pip install 'pytest>=9.0.3,<10'
.venv/bin/python -m pytest -q
```

Тесты используют временные базы, вымышленные профили и поддельный токен; сообщения в Telegram не отправляются. Русские тексты интерфейса, уведомлений и сообщений запуска находятся в [`static/ru.json`](static/ru.json).

```text
auction/       Flask-приложение, авторизация, локализация и процесс уведомлений
scripts/       Настройка бота и запуск временного теста
static/        Интерфейс и словарь сообщений
tests/         Автоматические тесты
demo.py        Локальная демонстрация
run.py         Точка входа веб-приложения
```

Дополнительные материалы: [план проекта](PLAN.md) и [исследование интерфейса](DESIGN_RESEARCH.md). Данные пользователей и локальное окружение в эту структуру репозитория не входят.
