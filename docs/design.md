# Решения об интерфейсе

Интерфейс Friends Auction начинается с каталога. Основные сведения для решения о ставке — фотография, название, цена, количество ставок и срок окончания. Общая дата торгов показана рядом с каталогом; подробные условия доступны в карточке лота и разделе правил.

## Принципы

- Нейтральный текст описывает действия и условия. Личная история организатора не занимает место в сценариях выбора вещи и ставки.
- Фотографии в каталоге имеют одинаковые пропорции. Для лота без фотографий используется нейтральная заглушка. В деталях доступны остальные фотографии, описание и состояние.
- Пользователь видит текущую цену, шаг и выбранную сумму перед подтверждением. При конфликте ставок интерфейс обновляет условия и требует нового решения.
- Поля заявки имеют отдельные подписи имени и фамилии. Объяснение видимости этих сведений расположено рядом с формой.
- Полномочия проверяет сервер. Отсутствие кнопки управления в интерфейсе не является механизмом защиты.
- Верстка адаптируется к мобильным экранам, использует системные шрифты и учитывает безопасные отступы. Основные действия и навигация должны оставаться доступны при открытой экранной клавиатуре.

Публичный каталог не показывает имена участников. Собственная история и статус доступны участнику, заявки и полная история — организатору. Подробные правила доступа описаны в [спецификации](specification.md).

## Структура реализации

HTML, CSS и JavaScript находятся в `static/`; отдельной сборки интерфейса нет. Тексты интерфейса, сервера и бота хранятся в `static/ru.json`, а исходный код обращается к ключам сообщений. Страницы получают обновления от API примерно раз в три секунды.

Полная поддержка динамической смены тем Telegram не реализована. Адаптацию к Telegram, загрузку фотографий, работу экранной клавиатуры, контраст и управление с клавиатуры необходимо проверять на целевых устройствах. Этот документ фиксирует решения, а не результаты пользовательского исследования или независимого аудита доступности.

## Ориентиры

Для проектирования использовались следующие материалы. Они служат справочными ориентирами, а не основанием для копирования чужого оформления:

- [eBay Design System: Item Tile](https://playbook.ebay.com/design-system/components/item-tile) — состав карточки аукционного лота.
- [Nielsen Norman Group: Product Photos on Listing Pages](https://www.nngroup.com/articles/product-photos-listing-pages/) — фотографии в каталоге.
- [Nielsen Norman Group: Ecommerce Product Pages](https://www.nngroup.com/articles/ecommerce-product-pages/) — содержание страницы вещи и основное действие.
- [Telegram Mini Apps: Design Guidelines](https://core.telegram.org/bots/webapps#design-guidelines) — особенности интерфейса внутри Telegram.
- [Apple Human Interface Guidelines: Text Fields](https://developer.apple.com/design/human-interface-guidelines/text-fields) — подписи полей ввода.
